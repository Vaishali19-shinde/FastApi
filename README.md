## 2. Prerequisites

Before setting up and running this project, ensure you have the following installed on your machine:

* **Python 3.8+** (Python 3.10 or higher recommended) — Check version with `python --version`
* **pip** (Python package installer) — Check version with `pip --version`
* **Git** — Check installation with `git --version`

```
